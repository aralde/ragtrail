# ragtrail eval — wixqa, cold vs warm

Generated by `ragtrail eval --dataset wixqa report`. Dataset: WixQA (MIT), help-center KB of 6,221 articles, built with subforest. Offline sections use no LLM. Answers judged by `sonnet` via `claude -p`, blind to the arm.

How to read the agent runs:

- Question selection is **matched first**: every test question whose warm recall was not a miss, then seeded random misses up to `--n`. When `--n` covers the whole test set, that is all questions.
- Both arms use the same model, tools, prompt and call cap; only the trail store differs.
- Questions that miss in both arms run under identical conditions, so their cold→warm change is run-to-run noise: read it as the noise floor.
