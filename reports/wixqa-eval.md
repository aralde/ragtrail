# ragtrail eval — WixQA, cold vs warm

Generated by `ragtrail eval report`. Dataset: WixQA (MIT), help-center KB of 6,221 articles built with subforest. Offline sections use no LLM; agent sections are small pilots.

How to read the agent pilots:

- Pilots are **stratified**: every test question whose warm recall was not a miss, filled with seeded random misses. They show the effect *when the cache hits*; the population effect is roughly the hit rate from the offline table times the per-hit effect.
- Both arms use the same model, tools, prompt and call cap; only the trail store differs.
- Accuracy is judged by the same small model, blind to the arm. Questions that miss in both arms run under identical conditions, so their cold→warm change is pure run-to-run noise: read it as the noise floor.
